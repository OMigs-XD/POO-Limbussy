# Pedra, Papel e Tesoura — Limbus Company

Jogo em **Python + Flask**. Quem fizer **5 pontos primeiro** vence.

## O que você precisa

**Python 3.9 ou mais novo** → https://www.python.org/downloads/
Na instalação, marque **"Add Python to PATH"**.

## Como abrir

1. Extraia a pasta do ZIP (não abra de dentro do ZIP).
2. Dê dois cliques em **`INICIAR.bat`**.
3. O navegador abre sozinho com o jogo.

Para fechar, feche a janela preta.

## Se não funcionar

Dê dois cliques em **`INICIAR_BACKUP.bat`**. Ele usa outro método
(cria um ambiente próprio e abre o navegador pelo Windows).

Ainda não abriu? Abra o navegador e digite: `http://127.0.0.1:5000`
(a janela preta precisa estar aberta).

## Jeito manual

Abra um terminal na pasta do jogo e rode:

```
pip install -r requirements.txt
python app.py
```

Depois acesse http://127.0.0.1:5000 no navegador.
